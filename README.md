# Skills Quiz 0 — Markdown Foundations

This short quiz checks whether you can write common GitHub Markdown syntax independently before starting the GitHub checkpoint sequence.

## Why this quiz exists

Markdown is used throughout the checkpoints in `README.md`, Issues, Pull Requests, task lists, reflections, and project documentation. This quiz isolates that skill so later checkpoints can focus on Git and GitHub workflows instead of basic formatting.

## Suggested time

**15 minutes**

This is a skills quiz, not a tutorial. Complete the tasks from memory or according to your teacher's quiz rules.

## Start the quiz

Copy this quiz into your own GitHub account:

[![Copy Exercise](https://img.shields.io/badge/Copy%20Exercise-%E2%86%92-1f883d?style=for-the-badge&logo=github&labelColor=197935)](https://github.com/new?template_owner=KLIS-CS&template_name=GitHub-Markdown-Skills-Quiz&owner=%40me&name=markdown-skills-quiz&description=Skills+Quiz+0:+Markdown+Foundations&visibility=public)

After the copy is created:

1. Open `markdown-quiz.md`.
2. Click the **pencil (Edit)** button.
3. Complete only the answer area between `QUIZ-START` and `QUIZ-END`.
4. Click **Commit changes** and commit directly to `main`.
5. Wait for the automatic grader to finish, then open **Issues**.
6. Open **Markdown Skills Quiz — Progress** to see your score and feedback.
7. When ready, use **Submit Quiz to KLIS-CS** so the mother repository independently re-grades your work.

> **Do not go to Actions and do not run a workflow manually.** Your commit to `markdown-quiz.md` automatically starts grading.

> Keep the copied repository **Public**. The KLIS-CS mother repository must be able to read `markdown-quiz.md` to verify the score.

> This quiz intentionally does **not** require a feature branch or Pull Request. Those skills are assessed later in CP2. The goal here is to measure Markdown only.

## What is tested — 100 points automatic

| Skill | Points |
|---|---:|
| H1 heading | 10 |
| Bold + italic text | 10 |
| Unordered + ordered lists | 15 |
| Link | 10 |
| Inline code | 10 |
| Fenced code block | 15 |
| Task list | 10 |
| Blockquote | 10 |
| Table | 10 |
| **Total** | **100** |

The grader checks the Markdown source between the quiz markers in `markdown-quiz.md`. Instructions outside that answer area do not count.

If your score is below 100, fix the missing Markdown evidence in `markdown-quiz.md` and commit again. The same Progress Issue will update automatically.

## Submit to the KLIS-CS mother repository

After completing the quiz, open the central submission form:

[![Submit Quiz](https://img.shields.io/badge/SUBMIT%20QUIZ-%E2%86%92-0969da?style=for-the-badge&logo=github)](https://github.com/KLIS-CS/GitHub-Markdown-Skills-Quiz/issues/new?template=markdown-quiz-submission.yml)

The mother repository automatically detects your public `markdown-skills-quiz` repository and independently runs the same Markdown rubric. You do **not** enter your score manually.

The central Submission Issue becomes the teacher-facing record:

```text
student repository
→ automatic Progress Issue /100
→ Submit Quiz
→ KLIS-CS mother repository re-grades markdown-quiz.md
→ mother Submission Issue shows verified /100
```

If you fix the quiz after submitting, add a new comment to the same Submission Issue to re-grade it.
